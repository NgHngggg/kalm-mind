# Kalm Mind - Gõ Mõ Tụng Kinh Online 🪷

Công cụ gõ mõ tụng kinh online với thiết kế tối giản, thanh tịnh và bình yên.

## ✨ Điểm nổi bật
- **Âm thanh chân thực**: Mô phỏng tiếng gõ mõ gỗ tự nhiên bằng Web Audio API với độ trễ 0ms.
- **Hình ảnh vector tinh tế**: Mõ gỗ chạm khắc hoa văn mây sen và dùi gõ bọc vải truyền thống.
- **Hiệu ứng mượt mà**: Chuyển động vung dùi, rung nảy của mõ và sóng âm lan tỏa khi gõ.
- **Hỗ trợ đa nền tảng**: Hoạt động trơn tru trên mọi thiết bị (chuột máy tính, chạm màn hình điện thoại/tablet, phím Space/Enter).
